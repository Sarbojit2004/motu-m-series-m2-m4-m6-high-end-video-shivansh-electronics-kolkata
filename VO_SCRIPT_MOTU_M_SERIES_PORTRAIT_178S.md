# Voiceover script — MOTU M-Series portrait short

**Deliverable:** `out/motu-m-series-portrait-short.mp4` — 1080 x 1920, 30 fps, 5,340 frames, 178.000 s
**Language:** English only.
**Tone:** Warm & Trustworthy, with spec callouts read in the Precise & Technical register.

Chosen because the whole narrative exists to remove the "am I settling?" anxiety, and that is
a mentor's job rather than a narrator's. Cinematic & Aspirational would oversell a desktop
interface and undercut the plain-fact spec claims; pure Precise & Technical would read as a
lecture and leave the emotional problem in Chapter 1 unanswered. So: a trusted engineer
talking across a desk, who gets exact when the numbers matter.

**This is not the long-form script trimmed.** It is written against this reel's own beat
structure, which collapses rather than shrinks the 298 s cut — see `src/schedule.ts`.

**Sync:** this file is generated by `npm run vo` from `src/schedule.ts` — the same data that
renders the picture. Every timestamp below is the in/out of the beat it narrates, so the script
cannot drift out of sync with the video. Re-run it after any schedule change.

**Recording:** no burned-in captions. Drop the finished read at `public/vo/voiceover-portrait.mp3`
and flip `HAS_VOICEOVER` in `src/Audio.tsx` to `true`. The music bed sits at roughly -22 dBFS RMS,
so a voice tracked around -16 dBFS sits cleanly above it without further ducking.

**Pace:** 370 words over 178 s = 125 wpm overall — inside the comfortable 140-165 band.
