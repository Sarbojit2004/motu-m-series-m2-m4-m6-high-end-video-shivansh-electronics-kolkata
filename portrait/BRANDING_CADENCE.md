# Branding cadence — MOTU M-Series portrait short (178 s, 1080x1920)

Generated by `npm run branding` from the same schedule that renders the video.

Every logo appearance renders through the `Logo` component, which draws the supplied file
**exactly as given — opaque, with its own white background intact, never alpha-keyed — directly
on the video with no box, card or plate**. The page palette is held in a near-white range
(`COLORS.paper` #F6F8FA) so that white ground reads as continuous with it. The full-frame
branding beats additionally use a flat page so nothing shows an edge behind the artwork.

All text and logos sit inside the Section 2.1 edge padding (56 x 52 px, pulled from the AVB
long-form build), so nothing critical can clip under downstream cropping or re-encode.
